## Summary of Items

### `evidence-gated-systems.md`

The manuscript separates source claims, reviewer interpretation, and inference through a fourteen-item evidence ledger. It reviews recoverable long-context memory, selective memory updates, security-fidelity measurement, layered agent security, protocol governance, medical-report evaluation, visual-token selection, verified Toffoli optimization, quantum-program reordering, and sparse Pauli decomposition.

Two older DEP-A artifacts covered papers in the source DEP, so the iterative-expansion rule applied. A cryptographic draw selected the prior CompressKV review. The new comparison distinguishes irreversible semantic eviction from recoverable multi-resolution memory and proposes a controlled evaluation under equal GPU bytes, CPU bytes, bandwidth, prefill cost, and latency.

## Insights and Relevance

The papers do not constitute one unified architecture, and their evidence classes are not interchangeable. Their common lesson is narrower: consequential system changes should be treated as candidates whose admission depends on evidence suited to the relevant failure mode. Learned tests, statistical benchmarks, human review, deterministic rules, and formal equivalence each support different assurance claims.

This entry is useful to future work on provenance-preserving semantic webs, agent evaluation, recoverable memory, security-utility trade-offs, governance envelopes, clinical evidence audit, and verifier-gated optimization.
