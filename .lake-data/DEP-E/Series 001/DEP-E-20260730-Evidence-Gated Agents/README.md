## Insights

1. Reliable agent workflows benefit from a typed artifact, a fast evidence stage, a slower adjudicator, and a durable decision trace.
2. Context can improve decisions or introduce new error modes; it should be treated as measurable evidence rather than unconditional prompt enrichment.
3. Proxy evaluators accelerate search but need disagreement tracking and slower grounding against execution, simulation, or expert review.
4. Current repository state may differ from a paper's evaluated system, so operational claims require version pinning.
5. High-stakes and physical workflows still require explicit human authorization at consequential boundaries.
