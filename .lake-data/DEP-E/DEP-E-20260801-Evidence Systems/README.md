## Item Summary

The manuscript synthesizes evidence acquisition, grounding, recovery search, provenance and authorization, executable validation, resource placement, and cross-scale coordination. It preserves source-specific metrics and limitations, then translates the shared pattern into bounded implementations, three safe exercise paths, and an evidence-ledger MVP concept.

## Insights

1. Evidence acquisition and evidence reasoning should be measured separately.
2. Recovery systems benefit from explicit search, cost, and stop conditions.
3. Provenance and authorization are independent safety controls, not substitutes for content scanning.
4. Executable, domain-specific, physical, or coordination checks must match the failure mode being evaluated.
5. State placement, evaluation budget, and temporal identity determine whether a system can be observed and controlled.
