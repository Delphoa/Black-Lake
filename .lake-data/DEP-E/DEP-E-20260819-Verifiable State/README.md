## Summary

Across ten studies of tool-using agents, long-horizon memory, scientific research, temporal medical evidence, hardware verification, probabilistic computing, and mechanistic interpretability, this artifact identifies one common engineering boundary: consequential decisions become more trustworthy when the system maintains typed, versioned, inspectable state between raw context and action.

The manuscript distinguishes source claims from reviewer interpretation, preserves limitations beside quantitative results, and does not treat efficiency, retrieval, or plausible prose as evidence of correctness. It recommends explicit provenance, state-transition checks, temporal evidence boundaries, executable validators, calibrated abstention, and evaluation of the full artifact chain.

## Key Insights

- Provenance must justify both tool choice and parameter values before execution.
- Retrieved memory needs scope, freshness, status, and conflict arbitration.
- Scientific-agent evaluation is strongest when protocols, code, evidence, and verdicts remain independently inspectable.
- Temporal systems must score when evidence became available, not only whether a final answer was correct.
- Systems and hardware optimization can reduce the cost of state management but cannot certify the resulting decision.
