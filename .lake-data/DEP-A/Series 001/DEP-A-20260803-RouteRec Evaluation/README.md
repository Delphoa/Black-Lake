Its central technical focus is: RouteRec follows this instance-wise selection line, but studies a cost-aware pool containing both traditional recommender agents and an LLM reranker agent under a strict out-of-fold protocol. Strict selection and aggregation versus quality-oracle headroom. We study this choice as task-aware agent ranking under cost constraints using RouteRec , a framework that compares request-level hard selection with item-level learned aggregation over four traditional recommender agents and one LLM reranker agent.
