Its central technical focus is: CEAA [ 8 ] is an implementation-oriented architecture proposed for developing cognitive embodied intelligent virtual agents that operate in real-time interactive virtual environments (see Figure Enhancing Virtual Agents through SLMs and Edge-Computing: An Exploratory Evaluation of Think and Memory Processes (left)). To support the development of intelligent interactive agents, the Cognitive Embodied Agent Architecture (CEAA) has been proposed as an implementation-oriented framework (see Figure Enhancing Virtual Agents through SLMs and Edge-Computing: An Exploratory Evaluation of Think and Memory Processes (left)) [ 8 ] , to support the development of intelligent interactive agents. Accordingly, this exploratory study is guided by the following research question: RQ: To what extent can SLMs partially operationalize selected aspects of CEAA’s Think and Memory components through service routing and structured memory handling for an edge-based virtual-world agent?
