Its central technical focus is: Motivated by this observation, we propose PIVOT ( Proxy Indexing Via One full-prefix Traversal ), a training-free, drop-in replacement for the DSA indexer that shares one prefix scan across a group of nearby queries instead of running one per query. This redundancy defines a fourth efficiency axis for accelerating token-level sparse attention, which is orthogonal to prior methods that operate along the token, head, and layer axes. We build on DSA (DeepSeek-AI 2025 ) , a token-level sparse attention mechanism with two components: a lightning indexer that selects the preceding tokens each query should attend to, and a Sparse MLA operator that attends only to the selected tokens.
