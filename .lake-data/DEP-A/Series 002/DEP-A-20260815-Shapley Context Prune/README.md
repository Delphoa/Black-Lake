Its central technical focus is: In this paper, we propose Shapley Context Pruning (SCP), a novel framework that transcends the interpretability limitations of existing heuristic methods and leverages cooperative game theory to improve coarse-grained reranking accuracy. In summary, while SCP builds upon established theoretical ingredients—Shapley values, Deep Sets, and cooperative games—its contribution lies in answering, for the first time, how Shapley attribution can be feasibly operationalized for context reranking, and in providing a novel blueprint toward more systematic and interpretable context pruning and management. We propose Shapley Context Pruning (SCP) as an attempt to construct an analytical framework based on cooperative game theory, a field thoroughly studied in economics and mathematics.
