We propose QV-PIC, a template-conditioned and query-aware dual-resolution framework for rendered-image PIC. As shown in Figure 6 , QV-PIC simultaneously improves F1 and reduces TTFT over uniform 120-DPI rendered-image PIC on HotpotQA, MuSiQue, TriviaQA, and NarrativeQA, indicating that enhancing only query-relevant images preserves useful visual-detail gains while avoiding unnecessary visual overhead on irrelevant pages.
