Its central technical focus is: To this end, we propose Pallas , a proactive KV-cache migration framework for low-latency LLM serving in AI-RAN. To exploit the aforementioned opportunities, we propose Pallas , which proactively moves inference-state preparation into the prefetching window and executes it in parallel with ongoing source-side inference. In contrast, Pallas prepares the target beforehand by overlapping historical-prefix reconstruction and incremental KV-cache streaming with ongoing source-side inference, and adaptively selects the prefetching window to reduce the work remaining on the post-handover interruption path.
