Its central technical focus is: (b) The harness of RetroAgent , which couples an LLM agent with a structured-memory environment. We introduce RetroAgent , an LLM agent for retrosynthesis planning built on a harness that couples the agent with a structured-memory environment, as shown in Figure 1 (b). To isolate the contribution of our structured-memory interface from the choice of base model, we reproduce the Retro-R1 two-action ( CALL/SELECT ) interface on the same Qwen3-4B-Instruct-2507 backbone used by RetroAgent , holding the model and RL training procedure fixed and varying only the interface.
