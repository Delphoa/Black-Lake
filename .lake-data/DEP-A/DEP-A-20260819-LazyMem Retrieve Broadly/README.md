Its central technical focus is: In this paper, we introduce LazyMem , a retrieve-then-construct agent memory system designed to address these trade-offs. We propose LazyMem , a retrieve-then-construct agent memory system that preserves raw interactions, retrieves broadly at query time, and constructs compact evidence through a lightweight model operating over overlapping parallel windows, avoiding irreversible write-time loss while bounding context length and latency. LazyMem addresses this as a lazy , retrieve-then-construct memory system (see Figure 1 ): messages are stored verbatim with no processing at write time, and all work is deferred to query time, where the system operates in three stages.
