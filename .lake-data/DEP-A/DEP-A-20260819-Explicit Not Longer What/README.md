Its central technical focus is: Within a run the compressor and the blind reader are the same model; because that makes each model its own grader, we additionally re-scored every stored memory with a single fixed judge (Haiku 4.5), which reproduces the same picture at 98 % 98\% agreement. Prior work named this failure factwashing , a rewrite that keeps a claim while washing away what made it checkable, and located where it concentrates: in a blind-labelled corpus of memory writes, 55 % 55\% of writes drawn from conversational hearsay lost the claim’s standing against 7 % 7\% drawn from business email ( p < 0.001 p<0.001 ), and an unmodified deployment of mem0 2.0.7 reproduces it (Kwon, 2026 ) . That control is what makes the comparison clean and also what makes it artificial: real notes are not matched pairs, and a real memory system writes its own claims rather than receiving ours.
