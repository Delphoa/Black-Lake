Its central technical focus is: Our contributions can be summarized as follows: We propose MaMe, a differentiable, and training-free token merging algorithm. We introduce MaRe, the inverse operation of MaMe for token restoration, also realized through efficient full-matrix operations. Additionally, we present MaRe, its inverse operation, for token restoration, forming a MaMe+MaRe pipeline for image synthesis.
