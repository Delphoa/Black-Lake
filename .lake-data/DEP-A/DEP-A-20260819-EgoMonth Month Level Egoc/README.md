Its central technical focus is: In parallel, recent long-video benchmarks have extended evaluation from short clips to movies and other long-form videos ( 10 ; 33 ; 39 ) , while video LLM architectures have explored learnable long-term memory ( 28 ; 16 ) and streaming-efficient computation ( 38 ) . To address this gap, we propose EgoMonth , a month-level egocentric video understanding benchmark for evaluating long-term spatiotemporal memory in real-world daily-life settings. This framework systematically probes long-term memory stability and logical integration, ranging from recurring behavioral pattern discovery to transient detail retrieval and multi-evidence spatiotemporal reasoning.
