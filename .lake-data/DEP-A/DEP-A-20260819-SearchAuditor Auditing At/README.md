Its central technical focus is: Automatically auditing and attributing where and how a long-horizon search agent fails remains an under-explored problem. To address this gap, we present a systematic study of auditing and attributing failures in long-horizon search agents, with three contributions. We therefore introduce SearchAuditBench, an expert-annotated benchmark of 1,243 failed deep-search trajectories (compared with prior benchmarks in Table 1 ), and SearchAuditor, a multi-perspective auditing framework with evidence-grounded adjudication.
