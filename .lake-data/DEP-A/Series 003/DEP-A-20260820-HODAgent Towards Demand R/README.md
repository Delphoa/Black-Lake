Its central technical focus is: We therefore present HODAgent , a System-2 embodied agent for on-demand human–humanoid interaction in service settings. HoloAgent-0 [ 49 ] couples monitored skills with persistent 3D memory and physical deployment, while JoyAI-VL-Interaction [ 45 ] supports event–driven multimodal interaction and response timing in streaming visual settings. The same interaction, planning, execution, and memory mechanisms are used in both simulations (e.g., Isaac Sim) and the physical robots (e.g., Unitree G1 and XPeng IRON); platform-specific adapters only translate observations and actions between the shared agent interface and the corresponding simulator or robot controller.
