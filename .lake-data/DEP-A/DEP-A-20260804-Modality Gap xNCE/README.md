Its central technical focus is: Eslami and de Melo ( 2024 ) proposes regularizing the contrastive loss using an intra-modal separation term, which again shows better retrieval and downstream utility. Wang and Isola ( 2020 ) investigate the properties of representations learned via a contrastive loss, and propose two quantities: alignment (closeness of features from positive pairs) and uniformity (of the distribution of features on the hypersphere). Performance degrades monotonically as r mix increases, mirroring the retrieval trade-off: larger mixing ratios reduce the modality gap but erode the discriminative structure needed for zero-shot transfer.
